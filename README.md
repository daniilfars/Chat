# SignalR Chat

Простой чат с личными сообщениями на SignalR.

## Функции
- Регистрация пользователя с уникальным ником
- Общий чат (все видят все сообщения)
- Личные сообщения
- Список онлайн-пользователей
- Уведомление о входе/выходе
